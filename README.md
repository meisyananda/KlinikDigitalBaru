# Klinik Digital — Domain: Klinik Digital

> Aplikasi manajemen klinik seluler berbasis Android yang dirancang untuk pasien agar dapat dengan mudah melihat jadwal dokter, melakukan booking konsultasi, serta mengelola profil dan dokumen KTP secara digital.

## ✨ Fitur Utama

* [x] Login dan Register pasien dengan validasi form terstruktur
* [x] Daftar 10 dokter spesialis menggunakan komponen `FlatList` yang dinamis
* [x] Detail informasi dokter dengan navigasi `Stack` dan fitur booking
* [x] Pengambilan foto KTP secara langsung menggunakan `expo-image-picker`
* [x] Penyimpanan data sesi login dan riwayat konsultasi secara persisten dengan `AsyncStorage`
* [x] Navigasi menu utama menggunakan `Bottom Tab Navigation`

## 🚀 Cara Menjalankan

```bash
git clone https://github.com/username/klinikdigitaluas.git
cd KlinikDigitalBaru
npm install
npx expo start --clear

```

Scan QR Code yang muncul di terminal menggunakan aplikasi **Expo Go** di HP Android kamu.
